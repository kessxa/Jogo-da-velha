# Jogo da velha

Jogo para duas pessoas no mesmo computador ou contra o computador. X joga em vermelho e O em azul; contra o computador, você joga com X.

Jogue diretamente no navegador: https://kessxa.github.io/Jogo-da-velha/

## Como executar

É necessário ter Python 3 instalado. Na pasta do projeto, execute:

```bash
python main.py
```

Abra http://localhost:8000 no navegador. Para parar o servidor, pressione Ctrl+C no terminal. Para depurar, execute `main.py` pelo depurador do seu editor.

O arquivo `index.html` contém a interface e as regras que executam no navegador; `style.css` define a aparência. `backend.py` e `main.py` permitem iniciar o servidor local opcional.
