# Jogo da velha

Jogo para duas pessoas no mesmo computador. X joga em vermelho e O em azul.

## Como executar

É necessário ter Python 3 instalado. Na pasta do projeto, execute:

```bash
python main.py
```

Abra http://localhost:8000 no navegador. Para parar o servidor, pressione Ctrl+C no terminal. Para depurar, execute `main.py` pelo depurador do seu editor.

O arquivo `backend.py` contém o servidor e as regras; `index.html` contém a interface e as interações; `style.css` define a aparência.
